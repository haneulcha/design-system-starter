## 우리 곡선 v0 (2026-07-26)

**한 줄:** naive의 뼈대(앵커 보존 + 보간)에 tailwind 손튜닝 평균 곡선의 모양을 입히고,
앵커 밝기에 맞춰 구간별로 아핀 리매핑한다.

구현: `src/lab/accent-scale/ours.ts` · 곡선 산출: `scripts/analysis/ours-curve-stats.ts`

### 구성 요소

1. **곡선 테이블 (OURS_CURVE)** — tailwind 17개 챠도 팔레트를 앵커(500) 기준으로
   정규화해 stop별 평균을 취함: L 배치 0.977 → 0.278 (900→950의 큰 점프 포함),
   채도 비율 0.092 → 1.0 → 0.42. 손튜닝의 "밝은 끝 색끼 유지"(R3)와 어두운 끝
   전개(R4)가 데이터로 들어온다.
2. **앵커 워프** — 앵커 L을 사다리에 꽂는 대신, 밝은끝→앵커 / 앵커→어두운끝 두
   구간을 각각 아핀 리매핑. 구간 내 상대 간격(=곡선 모양)이 보존되고, 양 끝은
   손튜닝 끝값에 고정되며, 리매핑이 단조라 극단 앵커(파스텔·딥)에서도 사다리가
   뒤집히지 않는다 (테스트로 고정: `tests/lab/algorithms.test.ts`).
3. **앵커 verbatim** — anchorIndex 자리에는 입력색을 그대로 반환 (R1).
4. **hue 고정** — 전 stop이 앵커 hue (R5).

### 벤치 위치 (2026-07-26, `accent-scale-bench-report.md`)

| 알고리즘 | tailwind ΔE | radix ΔE (독립) |
| --- | ---: | ---: |
| ours | .0236 † | **.0616** |
| naive (기존 1위) | .0803 | .1059 |
| hct | .0805 | .1937 |

† in-sample — OURS_CURVE가 tailwind 평균에 적합된 값이라 홈그라운드. **일반화
성능은 radix 열로 판단**: 독립 레퍼런스에서 naive 대비 42% 개선 (.1059 → .0616).
